# DET Reading Product Specification

## Purpose

DET Reading is a separate reading practice mode for modern, everyday English. It uses short book chunks and fast comprehension tasks. It is separate from SAT Reading scoring, progress, and recommendations.

## Initial Scope

- Levels: A2, B1, B2.
- Chunk length: 100-200 words, with a small exception for dialogue or a complete scene.
- Questions per chunk: 4 in the first version.
- Target time: 2-4 minutes per chunk, including questions.
- Audio is optional in the first text-only flow and can reuse existing sentence alignment.
- Vocabulary capture remains shared with the existing reading vocabulary system.

## Student Experience

1. Student opens `DET Reading`.
2. Student selects a book or resumes the current book.
3. Student reads one chunk with a timer.
4. Student answers the chunk questions.
5. Student receives immediate feedback and continues.
6. Progress is saved after reading and after each answer.
7. DET statistics remain separate from SAT statistics.

## Separate Data

DET records must be identifiable by a stable mode/content marker. Store separate progress, attempts, completion, and analytics. Shared vocabulary records must retain their source mode and book/chunk context.

## First Success Criteria

- Admin can create and publish a DET book.
- Student sees it in a separate DET library.
- Student can open the first chunk and answer its questions.
- Resume returns the student to the correct chunk.
- SAT lessons and statistics remain unchanged.
